# App Review Reply — Guideline 2.1 Information Request

MK Patch Librarian is a free, open-source patch editor for the Korg microKORG and microKORG S. It talks to the synth directly over MIDI SysEx through a connected MIDI interface. Browse patches, edit them, back them up, reorganize them. It's built for microKORG/microKORG S owners, and it does what Korg's own discontinued Sound Editor used to do.

Setup: there's nothing to log into. No accounts, no credentials, no network connection at all. Connect a MIDI interface to the synth's 5-pin DIN ports and the app finds it automatically. No sample files needed — it reads and writes patches straight from the hardware.

External services: none. The only thing it talks to is Apple's CoreMIDI framework, to reach the connected MIDI interface. No APIs, no SDKs, no analytics, no ads, no logins, no payments.

Regional differences: none. Same app, same features, everywhere.

Regulated industry or protected material: no. The app doesn't contain any third-party copyrighted material. "microKORG" is mentioned only to describe which hardware it's compatible with, per Apple's guideline 2.3.7 — I'm not affiliated with or endorsed by Korg.
